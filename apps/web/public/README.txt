ExamUdaan.in — Bird-Only Transparent Favicon

This package contains ONLY the bird mark.
There is NO square, rounded rectangle, colored background, text, or cap.

Use:
- favicon.ico for browsers
- favicon_32x32.png for browser tabs
- apple-touch-icon.png for Apple home-screen icon
- android-icon-192.png / android-icon-512.png for Android/PWA
- ExamUdaan_Bird_Only_Transparent_1024.png as the master transparent PNG

The bird has been tightly cropped with transparent padding so it appears as
only the bird mark in the browser tab, matching the requested look.
